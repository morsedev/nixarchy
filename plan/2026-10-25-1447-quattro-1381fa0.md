# Plan: edge takes Omarchy quattro 1381fa0

- Delete the launcher search-path substitution and our no-browser block,
  which upstream's #16422 makes redundant. On NixOS, `XDG_DATA_DIRS` holds
  `/run/current-system/sw/share`, `/etc/profiles/per-user/$USER/share` and
  `~/.nix-profile/share`. This was checked in a live session's
  `systemctl --user show-environment`.

  usage line and `omarchy:args`.

    `kiro-cli`.

    mise route with upstream's package names, as `kimi` does, with the same
